# Champion Lab Showdown Bridge

This local Chrome extension imports a verified Champion Lab team into the Pokemon Showdown team storage. It never reads account credentials, queues battles, or makes battle decisions.

## Install once

1. Open `chrome://extensions` in Chrome or Edge.
2. Turn on Developer mode.
3. Click Load unpacked.
4. Select this `showdown-bridge-extension` folder.

Keep the extension enabled. Back in Champion Lab, use the `一键导入 Showdown` button. The team is held by the local server for 90 seconds, then imported into the Showdown team library when the new tab opens.
